# Netflix Data Analysis

This project explores the Netflix dataset to uncover key insights about its content library — including genre trends, content distribution, country contributions, and release year patterns. It demonstrates the use of Python, Pandas, and Seaborn for end-to-end data analysis and visualization.

# Dataset

- Source: Kaggle – Netflix Movies and TV Shows

- Format: CSV

- Records: 8,000+ titles including Movies and TV Shows

- Features: Title, Director, Cast, Country, Release Year, Genre, Duration, Type, etc.

# Objectives

- Understand the composition of Netflix’s content library

- Identify the most dominant genres and countries

- Compare content types (Movies vs TV Shows)

- Track release trends over time

# Key Questions Answered

1. What is the distribution of Movies vs TV Shows on Netflix?

2. Which are the Top 10 most common genres?

3. Which countries contribute the most content?

4. Which year had the most content releases?

5. Which genres are most common in Movies vs TV Shows?

# Visulas Includede

- Bar plots for content type, genres, countries, and yearly trends

- Catplots for side-by-side genre comparisons

- Annotated charts with insights after each plot

# Data Cleaning & Processing

- Removed duplicates and null values

- Exploded multi-valued fields like genre and country into individual rows

- Renamed columns for clarity (listed_in → genre)

- Used grouping and filtering for analysis-ready transformations

#  Key Insights

- Netflix is dominated by Movies, especially in the Drama and International genres.

- United States and India are the top content contributors.

- TV Shows lean toward Crime, Reality, and Kids genres, while Movies focus on Documentary, Thriller, and International content.

- Content release peaked in 2019–2020, reflecting Netflix’s growth phase and COVID-19-driven demand.
